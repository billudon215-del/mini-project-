# Freelancer Web Place

GitHub Pages-ready frontend.

## Publish
1. Upload all files in this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save. GitHub will provide the live `github.io` URL.

The main `index.html` is already at the repository root.
